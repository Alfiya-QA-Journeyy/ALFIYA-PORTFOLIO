User Management API

API testing project using Postman to validate user management endpoints, HTTP status codes, response data and automated API assertions.

Project Type

API Testing

Tool

Postman

API

REST / JSON

01 — Objective

The objective of this project was to practice API testing using Postman by sending HTTP requests, validating response status codes, checking JSON response data and creating automated assertions.

02 — API Operations Tested

Method Endpoint Purpose Expected Status
GET /users/1 Retrieve a user 200 OK
GET /users/999 Validate non-existing user 404 Not Found
POST /users Create a new user 201 Created

03 — API Validations

I validated HTTP status codes and response body values. I also used Postman test scripts to automate assertions instead of checking every response manually.

pm.test("Status code should be 200", function () {
  pm.response.to.have.status(200);
});

pm.test("User name should be Leanne Graham", function () {
  pm.expect(pm.response.json().name).to.eql("Leanne Graham");
});

04 — Negative Testing

I tested a non-existing user ID to verify that the API returns the appropriate error response instead of returning an invalid user record.

GET /users/999

Expected: 404 Not Found

Result: 404 Not Found — PASS

05 — Postman Test Evidence

GET — User 1

Verified successful user retrieval with a 200 OK response.

GET — Invalid User

Verified negative testing using a non-existing user ID and 404 response.

POST — Create User

Verified user creation with a 201 Created response.

06 — Tools & Concepts

Postman • REST API • GET • POST • HTTP Status Codes • JSON • API Assertions • Negative Testing • Response Validation • JavaScript Test Scripts

07 — What I Learned

This project helped me understand how APIs communicate through HTTP requests and responses. I learned how to validate status codes, inspect JSON responses and write Postman assertions to automatically verify API behavior.
