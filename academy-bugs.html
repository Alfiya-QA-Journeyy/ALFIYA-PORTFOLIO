01 — Objective

The objective of this project was to explore a web application from a tester's perspective and identify defects by validating different user flows, input fields, buttons, forms and application behavior.

02 — Testing Approach

I tested the application using different functional and negative testing techniques. I verified expected behavior, entered invalid data, tested boundary conditions and checked how the application responded to unexpected user actions.

03 — Test Coverage

Functional Testing

Verified buttons, forms, links, navigation and core application functionality.

Negative Testing

Tested invalid inputs, incorrect data and unexpected user actions.

UI & Usability

Checked page behavior, loading issues, messages and user experience.
